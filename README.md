# 🐍 Python Arrays, Nested Lists & NumPy Operations

A structured Python reference script comparing standard lists, Python's built-in `array` module, and NumPy arrays for element-wise and multi-dimensional operations. This is the third installment in a Python learning repository.

## 📌 Topics Covered

The script (`Importing Numpy & ARRays for complex ARRAY, LIST operations.py`) is organized into commented sections for step-by-step practice:

1. **Array Typecodes & Memory Basics** – Understanding homogeneous data types and typecodes (`'i'` for signed int, `'f'` for float, `'b'` for char) compared to mixed-type Python lists[cite: 3].
2. **Nested List Indexing** – Accessing deeply nested elements inside multi-level Python lists[cite: 3].
3. **NumPy Element-Wise & Multi-Dimensional Operations** – Performing vectorized math (e.g., scalar multiplication) across 1D and 2D NumPy arrays[cite: 3].
4. **Creating & Iterating Arrays** – Initializing arrays with `array.array()` and printing elements using unpacking (`*a`) and `for` loops[cite: 3].
5. **Array Slicing** – Extracting sub-arrays using start/stop indices, negative indexing, and reversing with `[::-1]`[cite: 3].
6. **Modifying & Searching Arrays** – Mutating arrays and lists with `.append()`, `.extend()`, `.insert()`, `.remove()`, `.pop()`, and `.reverse()`, plus finding elements with `.index()` and `.count()`[cite: 3].
